# ASPNET-VX24TTK8-TONANHTUAN-WEBSITE
Bài chuyên đề ASP.NET

Kính chào Thầy cùng các bạn!

Mục tiêu: tạo được một website bán laptop đơn giản trên nền tảng ASP.NET

## Hướng dẫn chạy
1. Mở `src/WebsiteBanLaptop/WebsiteBanLaptop.csproj` trong Visual Studio có .NET 10 SDK.
2. Chọn cấu hình `https` và nhấn F5.
3. Trang BÁN HÀNG: https://localhost:7281`. TRANG QUẢN TRỊ: `https://localhost:7281/Admin/Login`.
4. Chạy `setup/TAO_TAI_KHOAN_ADMIN.bat` để tạo mật khẩu quản trị thử nghiệm.
